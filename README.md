One page that sums up the world's news of Wednesday 25 November 2026: a
newspaper-style front page with the day's three lead stories drawn as scenes
(Huawei's Brooklyn verdict, the Shenzhou-24 launch with Pakistan's first
astronaut, and Russia's leaked war-dead figures), a strip of the day's key
numbers, eight numbered story cards, a world map with pins for every story,
and a brief list of the rest of the day — 25 dated stories in all, each one
from Wednesday 25 November 2026. `generate.py` draws the picture with
Pillow; `main.py` is the graded entrypoint and copies the finished
`entry.png` to the output directory, byte for byte, every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
